# Introduction

Jhinity is a collection of premium 3D React components for SaaS marketing sites. Drop-in animated hero sections, shader backgrounds, and interactive 3D scenes — all built with React Three Fiber.

## Philosophy

Copy, paste, ship. No npm install of a 200KB component library. Components live in your codebase, where you can edit them. Inspired by [shadcn/ui](https://ui.shadcn.com).

## What's inside

- **Free tier** — 25+ components: hero backgrounds, interactive cards, text effects, scroll-linked scenes.
- **Pro tier** — Full section templates: animated hero sections, 3D product showcases, shader-driven feature grids. One-time purchase, lifetime access.

## Get started

Pick a component from the sidebar, copy the source, paste it into your project. Each component has a live preview, the full source, and the dependencies you'll need.
